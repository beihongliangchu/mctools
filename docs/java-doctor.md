# Minecraft Java 环境诊断工具 · 使用说明

**java-doctor v1.0**

## 这是什么

一个检查"你的 Java 装对没有"的小工具。

Minecraft 是 Java 写的，必须靠 Java 才能跑。但 Java 有很多个版本，装错了就启动不了，而且报错信息长得一模一样，看不出来是 Java 的问题。

这个工具会：

- 把你电脑上所有 Java 都找出来
- 告诉你这个游戏版本该用哪个
- 给出可以直接复制进启动器的参数和内存建议

它只读信息，不安装、不修改、不删除任何东西。

## 怎么用

直接双击 `java-doctor.bat` 就行。

它会先问你要不要指定游戏目录：

- 想看针对性的结论 → 把 `.minecraft` 文件夹拖到 bat 上
- 只想看看装了几个 Java → 直接双击，什么路径都不填

然后它会一个个检查每个 Java 的版本，每个大概一秒。不想填路径就直接回车跳过。

## 报告在哪

工具旁边会生成两个文件：

```
java-report.txt     给人看的报告，双击用记事本打开
java-report.json    给"诊断报告生成器"用的数据
```

## 报告里有什么

**一、结论** —— 分三档：

| 标记 | 含义 |
|---|---|
| `[确定]` | 就是这个问题，照着改 |
| `[可能]` | 能用，但不是最好的选择 |
| `[提示]` | 补充信息 |

**二、这台机器上的 Java** —— 版本号、32 位还是 64 位、装在哪。

**三、推荐的 JVM 参数** —— 根据物理内存和模组数量算出的内存建议，外加一套通用 JVM 参数。

**四、下一步怎么做**

## 游戏版本该用哪个 Java

| 游戏版本 | 需要的 Java |
|---|---|
| 1.7.10 ~ 1.16.5 | Java 8 |
| 1.17.x | Java 16 或 17 |
| 1.18 ~ 1.20.4 | Java 17 |
| 1.20.5 ~ 1.21.x | Java 21 |

> **装完一定要去启动器里把 Java 路径指过去。** 很多人装了新 Java 但还是崩，就是因为启动器还在用旧的那个。启动器里一般叫"Java 路径"或"Java 设置"。

## 关于内存和 JVM 参数

报告里会给一个建议的内存大小，比如 `-Xmx6144m`，意思是给游戏分 6G 内存。

- 分太少 → 加载整合包时崩，报 `OutOfMemoryError`
- 分太多 → 系统本身不够用，反而更卡
- 一般不要超过物理内存的 70%

报告里还会给一套 JVM 参数（社区通用的那套，俗称 Aikar 参数），作用是让垃圾回收少卡顿。可以直接复制到启动器的"JVM 参数"框里。

但这两种情况别照抄：

1. 整合包作者已经给了参数 → 以作者给的为准，不要两边混着抄
2. 启动器已经自动配好了 → 先用默认的试，出问题再改

## 怎么把结果发给我

闲鱼聊天窗口不能发文件，所以工具会自动帮你准备两样东西：

```
发给客服.txt     一段文字摘要
发给客服.png     一张结果卡片
```

分析完之后：

- **方法一**：工具已经帮你把文字复制好了。直接切到闲鱼聊天窗口，按 `Ctrl+V` 粘贴发送。
- **方法二**：工具会自动打开它所在的文件夹，把里面那张 `发给客服.png` 拖进聊天窗口发送。

两个都发一份也行，我看得越快。

图片里只写整合包的名字，不会带上你电脑的完整路径。

## 常见问题

**Q：提示"一个可用的 Java 都没找到"？**
A：那说明真的没装。去装一个，推荐这两个（免费、干净）：
- Eclipse Temurin（Adoptium）
- Microsoft Build of OpenJDK

**Q：检测到 32 位 Java 要紧吗？**
A：要紧。32 位 Java 最多只能分到 1.5G 左右内存，整合包必崩。换成 64 位的。

**Q：出来好几个 Java，我该用哪个？**
A：报告"结论"那一节会明确告诉你用哪个。多装的不用删，留着不影响。

**Q：检测花的时间有点长？**
A：每个 Java 都要启动一次去问版本，一个大概一秒。装了十个就得十秒，正常。

## 注意事项

- 老版本游戏（1.16.5 及更早）反而要用 Java 8，别把旧的删了。一台机器上同时装 Java 8 和 Java 17 是很正常的。
- 报告里的建议参数是通用配置，不是万能药。游戏崩了多半还是要看日志，那就用 `crash-doctor`。
- 本工具不联网，所有信息都在你本机处理。
