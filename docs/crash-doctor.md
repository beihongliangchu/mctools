# Minecraft 崩溃日志分析工具 · 使用说明

**crash-doctor v1.0**

## 这是什么

一个帮你"看懂报错"的小工具。

Minecraft 崩溃的时候，会在游戏目录里留下一份英文日志。里面其实写清楚了崩在哪、为什么崩，但那堆英文和代码路径基本没人愿意读。

这个工具会把那份日志从头到尾看一遍，然后用中文告诉你：

- 崩的原因是什么
- 是哪个模组 / 哪个设置的问题
- 接下来该怎么改

它只读文件，不会改你的游戏，也不会删除任何东西。

## 怎么用

最简单的办法：把下面的东西，用鼠标拖到 `crash-doctor.bat` 上面松手。

1. 游戏目录，比如 `C:\Users\你的名字\AppData\Roaming\.minecraft`
2. 整合包实例目录（里面能看到 `mods`、`config` 的那一层）
3. 或者直接拖单个文件
   - `crash-reports` 文件夹里的 `crash-xxxx.txt`
   - `logs` 文件夹里的 `latest.log`

拖上去之后会弹出一个黑窗口，等几秒钟，它自己就分析完了。

如果你不想拖拽，也可以直接双击 `crash-doctor.bat`，它会自己去找默认位置（AppData 里的 `.minecraft`）。找不到的话，把路径粘贴进去按回车就行。

## 报告在哪

分析完会在工具旁边生成一个文件：

```
crash-diagnosis.txt
```

这个就是报告，双击就能用记事本打开。想要人帮你看的话，把这个文件发出来就可以了 —— 不用再发那一大堆原始日志。

## 报告里有什么

**一、结论** —— 按重要程度排好，每条都分三种：

| 标记 | 含义 |
|---|---|
| `[确定]` | 基本可以断定就是这个原因 |
| `[可能]` | 对得上，但要结合实际情况再看 |
| `[提示]` | 顺带提一句，不一定是崩的原因 |

每条结论底下都有"依据"（从日志里摘出来的原句）和"怎么办"（具体操作步骤）。一条一条照着做就行。

**二、关键信息** —— 游戏版本、Java 版本、分配的内存、崩溃描述。还会告诉你这个游戏版本该用哪个 Java。

**三、模组列表** —— 你的 `mods` 文件夹里装了哪些东西（最多列 60 个）。

**四、下一步怎么做** —— 如果结论有好几条，这里会告诉你先动哪个。

## 几种最常见的崩溃

**1. 内存不够**

报告里写 `OutOfMemoryError: Java heap space`
→ 启动器里把最大内存调大。大整合包建议 4096 以上。

**2. Java 版本不对**

报告里写 `UnsupportedClassVersionError` 或者 `class file version 61.0`

| 游戏版本 | 需要的 Java |
|---|---|
| 1.7.10 ~ 1.16.5 | Java 8 |
| 1.17.x | Java 16 或 17 |
| 1.18 ~ 1.20.4 | Java 17 |
| 1.20.5 ~ 1.21.x | Java 21 |

注意：装完新 Java 之后，还要去启动器里把 Java 路径指过去，只装不改路径是没用的。

**3. 缺少前置模组**

报告里写 `Missing or unsupported mandatory dependencies` 或者 `NoClassDefFoundError`
→ 有个模组依赖的"前置"没装。报错里会点名是哪个。

**4. 模组冲突**

报告里写 `Mixin apply failed` 或者 `Incompatible mod set`
→ 两个模组改了同一处游戏代码。一般只能删掉其中一个。

**5. 显卡 / OpenGL 问题**

报告里写 `Pixel format not accelerated` 或者 `GLFW error`
→ 显卡驱动的问题。去显卡官网下最新驱动重装。

**6. 运行到一半才崩**

报告里写 `Ticking entity` 之类
→ 不是启动失败，是玩着玩着崩的。多半和存档里某个方块有关。试试新建一个世界，能进就是存档的问题。

## 怎么把结果发给我

闲鱼聊天窗口不能发文件，所以工具会自动帮你准备两样东西：

```
发给客服.txt     一段文字摘要
发给客服.png     一张结果卡片
```

分析完之后：

- **方法一**：工具已经帮你把文字复制好了。直接切到闲鱼聊天窗口，按 `Ctrl+V` 粘贴发送。
- **方法二**：工具会自动打开它所在的文件夹，把里面那张 `发给客服.png` 拖进聊天窗口发送。

两个都发一份也行，我看得越快。

图片里只写整合包的名字，不会带上你电脑的完整路径。

## 常见问题

**Q：黑窗口一闪就没了？**
A：说明它没找到游戏目录。不要直接双击，把 `.minecraft` 文件夹拖到 bat 文件上再松手。

**Q：报告里说"没有匹配到已知问题"？**
A：两种情况。一是日志被截断了，关键信息不在里面；二是这个报错还不在它的知识库里。这种时候把 `crash-diagnosis.txt` 发出来看。

**Q：会不会改坏我的游戏？**
A：不会。这个工具全程只读，不写入、不删除、不移动任何文件。报告是另外新建的一个 txt。

**Q：游戏目录里有中文路径可以吗？**
A：可以。但如果你遇到奇奇怪怪的"找不到文件"报错，建议把游戏换到纯英文路径下，老版本的游戏对这个比较敏感。

**Q：它能自动帮我修好吗？**
A：不能，它只负责诊断。怎么改还是得你自己动手 —— 不过报告里每一步都写清楚了。

## 注意事项

- 改游戏文件之前先备份，尤其是 `saves`（存档）和 `mods` 两个文件夹。
- 结论有好几条的时候，一次只改一样，改完就启动试一次。一次改好几样，出问题就不知道是哪一步起了作用。
- 报告里如果出现"可疑模组"（`Suspected mods`），那是崩溃报告自己点名怀疑的，优先从它开始排查。
