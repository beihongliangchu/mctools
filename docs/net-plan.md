## 这是什么

一个问答式的"我该怎么联机"顾问。

联机是新手问得最多、也最容易走弯路的问题。其实答案就那几种，但要看具体情况：在不在一个网里、玩哪个版本、肯不肯花钱。

这个工具问四个问题，然后直接给你：

- 推荐哪个方案
- 为什么推荐它
- 分步骤怎么做
- 这个方案会踩哪些坑
- 备选方案

全部是中文，答完就有一份可以直接发给朋友的说明。

## 怎么用

双击 `net-plan.bat`，然后按提示回答四个问题：

1. 你们是不是在同一个局域网？（同一个 WiFi、同一个宿舍）
2. 玩的是 Java 版还是基岩版？
3. 愿意花钱租服务器吗？（只有异地时才会问）
4. 有国外的人一起玩吗？

回答完，工具会直接给出方案。

## 它会给出哪些方案

**1. 局域网直连**

同一个 WiFi 下最省事的做法。什么都不用装，点几下就能玩。

**2. 租云服务器开服**

异地、想长期玩、愿意花钱。最稳定，服务器一直开着，不用房主一直挂电脑。

**3. Xbox 好友联机**

基岩版自带的官方方式，加好友就能互相进世界。

**4. 内网穿透 / 联机模组**

异地、不花钱。让房主临时当服务器，把世界暴露到公网。

如果选了"有国外玩家"，它会额外提醒线路和加速相关的事，指向同目录的《MC跨境联机教程》。

## 报告在哪

工具旁边会生成：

```
net-plan.txt
```

这份文件是为了一起玩的人写的，可以直接群发。里面记录了你的选择、推荐方案、步骤和注意事项。

## 几个容易被问到的点

**Q：为什么异地不推荐"房主开世界给别人进"？**
A：因为房主的家用宽带上行带宽很小，而且在家里网络里，外面的人根本找不到你的电脑。所以必须靠穿透工具或者服务器中转。

**Q：免费穿透和租服务器差在哪？**
A：免费穿透的瓶颈在房主的电脑和上行带宽 —— 房主不能关游戏、不能关电脑，延迟也高。服务器是独立的一台机器，谁先上谁后上都行。

**Q：离线账号能联机吗？**
A：能，但要看方式。走正版验证的服务器（`online-mode=true`）进不去；局域网和内网穿透一般不受影响。报告里会针对你的情况说明。

**Q：基岩版和 Java 版能一起玩吗？**
A：默认不能。需要额外的跨平台服务端，配置比较麻烦，不属于这个工具覆盖的范围。

**Q：四个问题里有我不确定的怎么办？**
A：按默认值来（直接回车）。默认是最常见的情况：同一局域网、Java 版、没有国外玩家。

## 注意事项

- 这个工具只给方案，不会去改你的网络设置，也不装任何东西。
- 具体到你家网络的实际情况，建议再配合 `mc-net-check` 测一下延迟、丢包和端口通不通。
- 别用来路不明的公共穿透节点，你的游戏流量会经过别人的机器。
