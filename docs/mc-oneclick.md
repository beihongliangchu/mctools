# MC 一键诊断 mc-oneclick

**双击一次，把整合包该查的全查完，最后只留一份能直接发出去的诊断报告。**

这是本仓库里唯一一个「有入口、不用选、不用打字」的工具：客户双击 `双击我.bat`，
它自己找到整合包、自己跑完六项检查、自己生成 `诊断报告.txt`，客户照屏幕上写的做就行。

## 它查什么

| # | 检查 | 查出来的是什么 |
|---|---|---|
| 1 | Java 环境 | 装了哪些 Java、这个整合包该用哪个、内存该给多少（附 Aikar 参数） |
| 2 | 模组依赖 | 缺前置、装重复、jar 损坏、游戏版本对不上 |
| 3 | **模组安全** | mods 里有没有**已公开披露的模组后门特征**（v1.5 新增，见下） |
| 4 | 崩溃日志 | 游戏为什么崩，把英文报错翻成中文结论（25 条规则，分确定/可能/提示） |
| 5 | **存档** | 世界名、存档版本、区块数、体积、上次游玩；缺 `level.dat`、**存档比游戏新**（v1.8 新增） |
| 6 | 网络环境 | 网卡、到路由器的延迟丢包、DNS、出口公网 IP、是不是在 CGNAT 后面、IPv6 |
| 7 | 联机线路 | 三段链路延迟、游戏端口通不通、路径 MTU、路由追踪（**要填一个联机地址**） |

前六项客户**什么都不用填**。第七项要先有联机地址，所以单独放在 `联机助手.bat` 里；
`存档助手.bat` 是另一个可选的入口（看某个坐标上的方块、搜一个键名、列玩家背包），
`补全助手.bat` 是第三个可选入口（缺前置 / 版本不符时查该装哪一版、生成清单、打开启动器），
同样不在主流程里 —— 主流程一个字都不问，「只会双击左键」的人看到光标在闪就会关窗口。

### 「模组安全」这一项（v1.5 新增）

背景：2026-10 社区曝光了模组后门（Simple-AutoClicker，作者 Sansrus）——
开关标记伪装成 `~/.ssh/unknown_hosts`，命中特定聊天口令就写入/删除它，
还往 log4j 塞全局过滤器专门删日志（HMCL 排查日志丢失时发现的）。

| 命中 | 判定 |
|---|---|
| jar 里任何 class 出现 `unknown_hosts` | 确定 —— 正常模组没有任何理由引用这个路径 |
| 出现公开披露的那两个触发哈希 `6fd719ce…` / `68d64631…` | 确定 |
| `~/.ssh/unknown_hosts` 存在且写着 `power=true` | 确定 —— 并直接教客户删掉它 |
| 模组元数据里**声明**的作者在已知风险名单里 | 提示（重名/冒用都可能，不替你定性） |

嵌在 `META-INF/jars/`、`jarjar/` 里的子 jar 也一起扫（并行，30 秒上限；
348 个模组热启动约 12 秒）。

> **它做不到什么，也写在报告明细里**：只认已知特征，认不出新变种；认不出
> "改了日志过滤"这种正常库同样能写出的行为；一个特征都没命中时写的是
> "没有发现**已知**后门特征"，不是"这个包很安全"。
> 只读边界：只解压读 jar，额外只测试 `.ssh\unknown_hosts` 这一个路径
> （不列目录、不读密钥）。

### 「补全助手」这一项（v1.9 新增）

PCL2 只认 `--update` / `--gpu` / `--memory` / `--wait`，HMCL 也没有命令行装模组的接口，
所以“让启动器自己补模组”在技术上做不到。v1.9 的做法是把能自动化的部分做掉：

1. 只跑「模组依赖」检查，拿到缺前置 / 版本不符的结构化清单；
2. 用 BBSMC（国内直连、有中文名）优先、Modrinth 兜底，查出每个模组支持当前
   游戏版本 + 加载器的最新一版；
3. 写成 `模组补全清单.txt`（版本号、文件名、页面链接、能直连的下载链接）；
4. 打开客户机器上的 PCL2 / HMCL / BakaXL，客户照着清单在启动器里点两下装好。

它**不下载、不删除、不移动 mods 里的任何文件**。清单里没查到的模组会单独列一段，
给 BBSMC 搜索链接，让客户或帮助者自己搜。

## 产出

**v1.9 起不再生成 PNG 卡片，也不生成「发给帮助者.txt」**，只留纯文本报告：

跑完自动做两件事：

1. 生成 `诊断报告.txt`
2. 打开文件夹并选中它，窗口里用大字告诉客户怎么发

落在工具自己文件夹里的文件：

| 文件 | 是什么 |
|---|---|
| `诊断报告.txt` | 完整报告，含环境、每项检查的结论和修复建议，客户直接复制发送 |
| `模组补全清单.txt` | 只有跑了 `补全助手.bat` 才有；列出缺前置 / 版本不符该装哪一版 |

`联机助手.bat` 产出 `联机检测报告.txt`，以及 `联机方案.txt`（选了「我该用哪种联机方式」时）。
`存档助手.bat` 产出 `存档检查报告.txt`（查坐标 / 搜键名 / 看背包的明细都在里面）。

`补全助手.bat` 产出 `模组补全清单.txt`（该装哪个版本、去哪下载、要换掉哪个旧 jar）。
它**只出清单，不改 mods**：下载和安装仍由客户在启动器里完成。

> 聊天窗口不能发文件时，直接打开 `诊断报告.txt`，全选复制文字发过去就行。
> 不再生成图片，也就没有图片压缩、字体缺失、高分屏糊掉这些问题。

## 怎么用

1. 解压，得到一个 `MC一键诊断` 文件夹，**不要在压缩包里直接双击**
2. 把这个文件夹**整个放进你要检查的整合包文件夹里**
   （启动器 `versions\` 下面那个、里面有一个 `mods` 文件夹的）
3. 进到整合包文件夹里，双击 `MC一键诊断\双击我.bat`，等它跑完（六项检查，一般几十秒）
4. 照屏幕上写的两步做：打开 `诊断报告.txt` → 全选复制 → 粘到聊天窗口发送
5. 想知道存档里到底存了什么（箱子内容、机器的数值），双击 `存档助手.bat`，按菜单选
6. 联机有问题时，双击 `联机助手.bat`，按菜单选
7. 报告里报「缺前置」或「版本对不上」时，双击 `补全助手.bat`：它会生成
   `模组补全清单.txt` 并打开启动器，照着清单在启动器里装

> **为什么必须放进去？** 一台机器上通常有好几个整合包。工具放在整合包文件夹里，
> 它从自己所在目录往上找一层就命中了，**不会认错包**；放桌面/下载文件夹只能靠
> "挑最近改过的那个"，那只是兜底。
>
> 老用法也仍然有效：把整合包文件夹直接拖到 `双击我.bat` 上，不用搬文件夹。
> 程序在"没找到整合包"那一屏会把这个备选写出来。

## 隐私

* **只读**：不修改、不移动、不删除你的任何游戏文件（**存档也一样**）。
* `补全助手.bat` 也遵守这条：它只在工具文件夹里写 `模组补全清单.txt`，不碰 mods。
* 读存档只发生在「检查存档」这一步和使用「存档助手.bat」时，而且只读不写。
* 不上传任何文件。
* 联网只做两件事：查一次「我出去的公网地址是什么」，以及客户给了联机地址后测那条线路。
* 报告里**只写整合包的名字，不写路径**。报告里出现用户目录的地方会被换成 `…`，
  Windows 用户名不会跟着报告发出去。

## 运行条件

* Windows 10 / 11
* 系统自带的 PowerShell（不需要管理员权限）
* .NET Framework 4.x（Win10/11 自带）
* 程序主体是一个 C# 编译的 `.dll`，客户双击的是 `.bat` —— 所以**不会弹 SmartScreen 蓝框**

## 源码与构建

```
双击我.bat   ─┐
              ├→ main.ps1       ─┐
联机助手.bat  ─┤   net-assist.ps1 │
存档助手.bat  ─┤   save-assist.ps1 │
补全助手.bat  ─┘   fix-assist.ps1 ─┴→ lib\McOneClick.dll（C#，系统自带 csc.exe 编译）
```

| 文件 | 作用 |
|---|---|
| `src\*.cs` | 全部逻辑（Java / 模组 / 崩溃 / 存档 / 网络 / B 档联机检测 / 联机方案 / 报告 / 补全助手） |
| `src\Notice.cs` | 版权声明的唯一来源（控制台、报告一起变） |
| `build.ps1` | 编译成 `lib\McOneClick.dll`，顺手给 `src\*.cs` 和根目录 `*.ps1` 补 BOM |
| `release.ps1` | 打包到 `发布\MC一键诊断-v1.9.zip`，带六道分发自检 |
| `_test\` | 对照测试（10 个真实整合包）+ **4 个合成存档靶子**（1.7.10 / 1.13 / 1.16.5 / 1.18）+ 分支打靶，**不随包发布** |

```powershell
# 编译（不需要装 .NET SDK，用系统自带的 csc.exe）
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1

# 打包（必须先 build，中间不要再 build）
powershell -NoProfile -ExecutionPolicy Bypass -File release.ps1
```
