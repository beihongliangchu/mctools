## 一、这个工具是干什么的

联机玩 Minecraft 的时候卡、走路被拉回去、挖方块又弹回来，用这个工具查原因。

它不修复任何东西，只负责把数据测出来：从你这台电脑到路由器、到联机服务器（FRP 节点）、到主机的这三段线路，各自的丢包率、延迟和抖动是多少，外加路由走向和 IPv6 能不能用。

拿到报告之后就能判断：是该换联机方式、该换线路节点，还是该去优化开服那台电脑。

适用场景：用 frp、樱花frp、OpenFrp、Astral、EasyTier、ZeroTier、蒲公英之类的工具联机，出现卡顿或回弹时。

## 二、运行条件

|  |  |
| --- | --- |
| 系统 | Windows 10 / 11 |
| 软件 | 不需要另外装任何东西，PowerShell 是系统自带的 |
| 网络 | 需要联网，它本来就是测网络的 |
| 权限 | 普通用户即可，不需要管理员权限 |

重要：必须在会卡、会回弹的那台电脑上运行。在一台没参与联机的电脑上跑，测出来的是那台电脑的线路，没有意义。

## 三、怎么用

- 第 1 步  把压缩包解压到一个普通文件夹里（桌面就行，路径里有中文也没关系）。
  - 不要直接在压缩包里双击运行，一定要先解压出来。
  - `mc-net-check.bat` 和 `mc-net-check.ps1` 必须待在同一个文件夹里。
- 第 2 步  先把联机软件打开，确认现在确实能连上主机、能进游戏。
  - 测试期间不要关联机软件，否则测不到局域网地址那一项。
- 第 3 步  双击 `mc-net-check.bat`
- 第 4 步  它会问你两个地址，逐个填进去回车：

  - **FRP 节点地址**：就是你联机面板或者配置文件里显示的那个服务器地址，可以带端口。例如 `cn-2.frp.example.com:7000`。不知道填哪个就留空，直接回车跳过。
  - **主机地址**：就是你在游戏里"直接连接"填的那个地址。例如 `10.126.126.1:25565` 或者 `1.2.3.4:25565`。不知道就留空回车跳过。

- 第 5 步  等 2 到 4 分钟，中间不要关窗口。
- 第 6 步  跑完会在同一个文件夹里生成 `mc-net-check-result.txt`。把这个 txt 文件发给我就行。

测试期间建议关掉迅雷、网盘同步、直播、系统更新，这些会占用带宽，让结果失真。用无线网的话尽量离路由器近一点，能插网线最好插上。

## 四、报告里那三个数字是什么意思

- **丢包率**：最重要的指标。Minecraft 走 TCP，丢一个包就要重传，重传期间位置同步全部卡住，表现出来就是回弹。0% 才算正常，超过 1% 就能明显感觉到。
- **延迟**：看平均值，但更要看最大值和 P95（95% 的包都在这个值以内）。平均 60 毫秒、最大 500 毫秒，比稳定 150 毫秒难受得多。
- **抖动**：相邻两个包延迟的波动幅度，以及整体标准差。这个指标比平均延迟更能预测回弹：延迟高但稳定还能玩，延迟不高但抖得厉害，会频繁被服务器判定移动异常，然后把你拉回原位。

## 五、报告里的判定是怎么来的

|  |  |
| --- | --- |
| 丢包 5% 以上 | 严重丢包 |
| 丢包 1% 到 5% | 轻微丢包 |
| 抖动 30 毫秒以上 | 抖动严重 |
| 抖动 12 到 30 毫秒 | 抖动偏大 |
| 平均延迟 120 毫秒以上 | 延迟偏高 |
| 平均延迟 80 到 120 | 延迟一般 |
| 连续丢包段 3 次以上 | 成片丢包，典型的线路拥塞或跨网互联问题 |

## 六、报告结果怎么看

先看报告里"结论摘要"那一节，三种情况对应三个方向：

### 情况一：本机到路由器就不行

是你自己这边的问题，和联机软件、和主机都没关系。换网线、换路由器位置、重启路由器。

### 情况二：本机到节点不行

是线路问题。处理顺序：

1. 能点对点直连就直连（frp 改用 XTCP 模式，或换成 EasyTier 这类）
2. 有公网 IPv6 的，直接走 IPv6 连主机
3. 只能中转的话，换一个离你近、和你同一个运营商的节点

### 情况三：全部良好

网络没问题，要去查开服那台电脑。在游戏里执行 `/forge tps`（NeoForge 用 `/neoforge tps`，Paper 用 `/tps`），满值是 20.0，低于 19 就是服务端在掉帧，回弹是它造成的。

游戏里的延迟和上面配合着看更准：

| 服务端 TPS | 你的延迟 | 结论 |
| --- | --- | --- |
| 20.0 满 | 稳定 40 到 80ms | 线路正常，查客户端或整合包本身 |
| 20.0 满 | 忽高忽低或 150ms+ | 线路问题 |
| 低于 19 | 不管多少 | 服务端问题 |

## 七、注意事项

1. 本工具用 ping 测量。有些服务器、节点或者主机防火墙会直接屏蔽 ping，这时报告会显示"完全不通"，但游戏其实能正常连。看到 100% 丢包，先确认游戏进不进得去，再下结论。
2. 测的是 ping，游戏实际走 TCP，两者不完全等价。但"延迟高 + 抖动大"在任何协议下都是真问题，这一条不会误判。
3. 只能测网络，测不了服务端性能、插件冲突、客户端帧率、整合包问题。
4. 结果只反映跑的那几分钟。怀疑晚高峰卡的话，晚上和白天各跑一次对比着看。
5. 家用路由器普遍限制 ping 的频率。如果报告里"本机到路由器"那段显示延迟极低（低于 5 毫秒）却报少量丢包，工具会标成"存疑"，这种情况可以忽略。
6. 报告里有你的内网地址和网关信息。如果不想让别人看到，发之前可以把"本机概况"那一节删掉再发，不影响我判断问题。

## 八、常见问题

### 问：双击 `mc-net-check.bat` 一闪就没了

看是不是没解压，直接在压缩包里点了。必须先把压缩包解压出来再双击。另外确认 `mc-net-check.bat` 和 `mc-net-check.ps1` 在同一个文件夹里。

### 问：Windows 弹出"已保护你的电脑"蓝色提示

这是 SmartScreen 对来源未知的文件的常规提醒，不是报毒。点"更多信息"，再点"仍要运行"即可。

### 问：提示"禁止运行脚本"或者执行策略报错

用 `mc-net-check.bat` 启动，它自带绕过参数，不要直接双击 `.ps1`。

### 问：报告打开是乱码

报告是 UTF-8 编码，用记事本或者 VS Code 打开，别用老式的 GBK 编辑器。

### 问：显示 100% 丢包，但游戏能玩

见上面注意事项第 1 条，对端屏蔽了 ping，这一项可以忽略。

### 问：FRP 节点地址不知道填哪个

填面板上显示的那个服务器地址，不是你游戏的端口。实在找不到就留空，只测主机地址那一项，也能看出主要问题。

### 问：能不能在别的电脑上帮我测

不行。网络测量的结果只对跑测量的那台电脑到目标的线路有意义。必须是会卡的那一方自己跑。

## 九、安全说明

- 只做网络测量和读取本机网卡信息，不修改系统任何设置
- 不会上传任何东西，报告只存在你本地的 txt 文件里
- 不需要管理员权限
- 两个文件都是纯文本，可以用记事本打开自行检查

唯一会产生的文件是 `mc-net-check-result.txt`，就是你发回来的那份报告。
